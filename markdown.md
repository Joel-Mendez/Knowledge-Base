# What is Markdown? 
Markup language that allows basic text formatting. Commonly used in documentation. Extension type `.md`

# Headings 
Use `#` for headings. The number of `#` determines the level of the heading.

# Text Formatting
- **Bold**: `**text**` or `__text__`
- *Italic*: `*text*` or `_text_`
- ***Bold and Italic***: `***text***` or `___text___`       
- ~~Strikethough~~: `~~text~~`

# Lists
- Unordered List: Use `-`, `*`, or `+` followed by a space.
- Ordered List: Use numbers followed by a period and a space.

# Links and Images
- Links: `[link text](URL)`
- Images: `![alt text](image URL)`

# Code Blocks
- Inline Code: Use backticks `` `code` ``
- Code Block: Use triple backticks \``` for multiple lines of code. Optionally specify the language for syntax highlighting, e.g., \```python

# Blockquotes
Use `>` followed by a space to create blockquotes.
> This is a blockquote.

# Tables
Use pipes `|` to separate columns and hyphens `-` to create the header row.
| Header 1 | Header 2 |
| --- | --- |
| Row 1 Col 1 | Row 1 Col 2 |
| Row 2 Col 1 | Row 2 Col 2 |

# Horizontal Line 
Use three or more hyphens `---`, asterisks `***`, or underscores `___` on a line by themselves to create a horizontal line.

# Special Characters
To display special characters, use a backslash `\` before the character. For example, to display a literal asterisk, use `\*`.
