# pyenv

Helpful in managaging virtual environments in Python and insulating project dependencies. 
 

**Creating a Virtual Environment**
- Go to project root directory

- Create virtual environment: `python3 -m venv env-name`

**Activate virtual environment:** - `source env-name/bin/activate`

- You'll see your terminal prompt change to reflect the current env: `(env-name) $`

- You can now install packages withink the environment without affecting other Python projects. 
`pip install package-name`

**Deactivating Virtual Environment**
`deactivate`
