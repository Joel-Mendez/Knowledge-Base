# What is HTML?
HTML (HyperText Markup Language)
Determines the layout of your structure. 

# Hello World!
```html
<!DOCTYPE html>
<html>
    <head>
        <title> Webpage Title </title>
    </head>
    <body>
        <h1> Heading </h1>
        <p> Web Conent </p>
    </body>
</html>
```
